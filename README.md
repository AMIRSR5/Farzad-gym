# راهنمای راه‌اندازی — تبدیل متن به گفتار فارسی

این پروژه دو بخش دارد:
1. **`index.html`** — رابط کاربری، همانی که روی GitHub Pages آپلود می‌کنی.
2. **`supabase-function/index.ts`** — یک Edge Function که کلید سرویس صدا را مخفی نگه می‌دارد و درخواست‌ها را به موتور Text-to-Speech ارسال می‌کند.

چون GitHub Pages فقط فایل استاتیک سرو می‌کند، کلید API نباید مستقیم توی `index.html` باشد؛ به همین دلیل Supabase به‌عنوان واسطهٔ امن استفاده شده.

موتور صدا: **Azure Neural TTS** با دو صدای فارسیِ طبیعی —‌ فرید (مردانه) و دلارا (زنانه). این موتور اعراب‌گذاری متن (َ ِ ُ) را برای تلفظ دقیق‌تر در نظر می‌گیرد، پس هرجا تلفظ کلمه مبهم است، اعراب‌گذاری کن.

## مرحله ۱ — گرفتن کلید Azure Speech

1. وارد [portal.azure.com](https://portal.azure.com) شو (حساب رایگان کافی است — سطح رایگان ماهانه حدود ۰٫۵ میلیون کاراکتر صدای عصبی رایگان می‌دهد).
2. یک منبع «Speech service» بساز.
3. از بخش «Keys and Endpoint»، یکی از دو کلید و نام «Region» (مثلاً `westeurope`) را بردار.

> نکته: به‌خاطر تحریم‌ها، دسترسی مستقیم به برخی سرویس‌های ابری از داخل ایران ممکن است نیاز به VPN داشته باشد. این محدودیت مخصوص این پروژه نیست و تقریباً همهٔ سرویس‌های باکیفیت TTS (Azure، Google، ElevenLabs) را شامل می‌شود.

## مرحله ۲ — دیپلوی کردن Edge Function در Supabase

با CLI Supabase (اگر نصب نداری: `npm install -g supabase`):

```bash
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase functions deploy tts --no-verify-jwt
supabase secrets set AZURE_SPEECH_KEY=xxxxxxxx AZURE_SPEECH_REGION=westeurope
```

فلگ `--no-verify-jwt` باعث می‌شود بدون نیاز به هدر احراز هویت هم بتوان از GitHub Pages به تابع درخواست زد. اگر ترجیح می‌دهی تابع محافظت‌شده باشد، این فلگ را حذف کن و کلید anon پروژه‌ات را در بخش «تنظیمات اتصال» داخل خود اپ وارد کن.

آدرس نهایی تابع چیزی شبیه این خواهد بود:
```
https://YOUR_PROJECT_REF.supabase.co/functions/v1/tts
```

## مرحله ۳ — آپلود روی GitHub Pages

1. فایل `index.html` را در یک ریپازیتوری روی GitHub قرار بده (می‌تواند تنها فایل ریپو باشد).
2. در تنظیمات ریپو، بخش **Settings → Pages** را باز کن و شاخه‌ی مربوطه (مثلاً `main`) را به‌عنوان منبع Pages انتخاب کن.
3. بعد از چند دقیقه، سایتت روی آدرسی شبیه `https://USERNAME.github.io/REPO/` بالا می‌آید.

## مرحله ۴ — وصل کردن اپ به تابع

1. سایت را باز کن.
2. در بخش «تنظیمات اتصال»، آدرس Edge Function را وارد کن.
3. اگر تابع را با احراز هویت دیپلوی کردی، کلید anon پروژهٔ Supabase را هم وارد کن.
4. «ذخیره» را بزن — این تنظیمات در مرورگر خودت (localStorage) ذخیره می‌شود، نه جایی مرکزی.

از این به بعد می‌توانی متن فارسی بنویسی، صدا (فرید یا دلارا)، سرعت و زیر‌و‌بمی را تنظیم کنی، صدا را بشنوی و فایل MP3 را دانلود کنی.

## تغییر موتور صدا

اگر خواستی به‌جای Azure از سرویس دیگری (مثلاً ElevenLabs مدل v3 که فارسی را پشتیبانی می‌کند، یا Google Cloud TTS) استفاده کنی، فقط کافیست داخل `supabase-function/index.ts` بخش فراخوانی API را با API آن سرویس عوض کنی؛ بقیهٔ اپ (رابط کاربری، دانلود، پخش) بدون تغییر کار می‌کند.
